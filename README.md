EV Resale Value Prediction 🚗⚡
A machine learning project that predicts the resale value of electric vehicles based on vehicle specifications and usage-related features.

📊 Dataset
* 3,000 EV records
* 25 features
* Target: EV Resale Value

🛠️ Tech Stack
* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Scikit-learn
* Lovable (AI-assisted application development)

🔄 Workflow
Data Cleaning → EDA → Feature Engineering → Model Training → Model Comparison → Prediction

🤖 Models
* Linear Regression
* Decision Tree Regression
* Random Forest Regression

Results

Linear Regression
* R² Score: 0.90
* MAE: 1,510.90

💻 Application
Built an interactive application that allows users to enter EV details and get an estimated resale value.
